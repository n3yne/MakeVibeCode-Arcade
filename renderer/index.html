Help — Getting Started

MakeVibeCode Arcade uses an AI model to help write your game code. Google's Gemini models offer a free tier with a generous number of requests, so that's the quickest way to get started.

  1. Go to https://aistudio.google.com/apikey Copied! in your web browser.
  2. Sign in with your Google account (create one for free if you don't have one).
  3. Click Create API key.
  4. Choose Create API key in new project (or pick an existing project if you have one).
  5. Copy the API key that appears — it's a long string of letters and numbers.
  6. In MakeVibeCode Arcade, click the gear icon (Settings) in the top-right toolbar.
  7. Set AI Provider to Google (Gemini).
  8. Paste your key into the API Key field.
  9. Click Load Models next to the API Key field — this checks your key works and fetches the list of available models.
  10. From the Model dropdown, choose gemini-3.1-flash-lite — it's fast and free for a large number of requests.
  11. Click Save Settings. You're ready to start chatting with the AI!

Keep your API key private — don't share it or paste it anywhere except this app's Settings panel. If you ever think it's been exposed, you can delete it and create a new one at the same Google AI Studio page.
